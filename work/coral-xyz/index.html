Flutter apps had no clean way to talk to Solana programs. Each one hand-rolled its own encoding. coral_xyz reads a program's IDL at runtime and gives Dart the same program API TypeScript developers have.

  1. One API across Anchor, Quasar and Pinocchio programs.
  2. Borsh encoding, zero-copy account decoding, and PDA derivation straight from the IDL's seeds.
  3. Typed builders: accounts, signers, then rpc, simulate or view. Events decode as they arrive.
  4. A code generator for typed clients, and in-process testing through Quasar SVM bindings.
