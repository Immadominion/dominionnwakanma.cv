Walrus stores large files across a network of nodes. Dartus lets a Flutter app store and read them in a few lines, with three modes depending on how much you want to rely on a server.

  1. HTTP mode through publishers and aggregators, for the simplest setup.
  2. Relay mode, and a direct mode that erasure-codes on the device through Rust and signs with the user's own wallet.
  3. Quilts and blob inspection, with a demo app that exercises every feature.
  4. The Walrus Foundation calls it "a Walrus RFP project built by Dominion".
